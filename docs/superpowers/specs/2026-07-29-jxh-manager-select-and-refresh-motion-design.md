# Jxh Manager 自定义下拉菜单与刷新动效设计

- 日期：2026-07-29
- 状态：已确认，待实现
- 首次接入范围：`jxh-manager` 统计分析页
- 视觉依赖：`2026-07-28-jxh-manager-ui-design.md`

## 1. 目标

统计页当前使用原生 `<select>`。控件闭合时可以通过 CSS 调整，但 Windows 浏览器展开的选项菜单仍使用系统样式，与管理端的红粉品牌色、边框和圆角不一致。统计数据刷新时，加载提示和数据内容会直接改变卡片高度，造成瞬间跳动；新数据替换也缺少方向明确的过渡反馈。

本次实现以下目标：

1. 建立一个可供全管理端复用的自定义下拉菜单组件。
2. 首次替换统计页全部七个下拉菜单，其他页面后续逐步迁移。
3. 数据刷新时让卡片从旧高度平滑过渡到真实新高度，不设置固定高度。
4. 新内容出现时使用轻量上浮动画，明确表达数据已经更新。
5. 保持键盘、焦点、读屏和减少动态效果偏好可用。

## 2. 自定义下拉菜单

新增全局基础组件 `AppSelect`。组件接收字符串 `modelValue`、选项数组、字段名称、可访问名称、尺寸和禁用状态，使用 `update:modelValue` 与 `change` 事件接入表单。

触发器使用项目现有控制高度、`4px` 圆角、灰色边框和白色表面。展开状态使用品牌红色边框及焦点环，右侧使用 Lucide `ChevronDown`，不得继续显示浏览器原生箭头。

选项菜单通过 `Teleport` 渲染到 `body`，使用固定定位，避免被卡片的高度动画或 `overflow` 裁切。菜单宽度不小于触发器，最大高度受当前视口可用空间限制；下方空间不足时自动显示在触发器上方，并在滚动或视口变化时重新定位。

菜单外观：

- 白色表面、`1px` 灰边框、`6px` 圆角和轻量浮层阴影；
- 当前选项使用浅粉表面、深红文字和 `Check` 图标；
- 键盘高亮与鼠标悬停使用同一视觉状态；
- 展开使用 `opacity + translateY(4px)` 的 `140ms` 动画；
- 长列表在菜单内部滚动，不让页面产生新的横向或纵向溢出。

交互必须支持：

- 点击触发器展开或关闭；
- 点击外部关闭；
- `ArrowUp`、`ArrowDown`、`Home`、`End` 移动高亮；
- `Enter` 或空格确认；
- `Escape` 关闭并把焦点还给触发器；
- 选中后更新值、关闭菜单并恢复触发器焦点；
- 使用 `listbox` / `option`、`aria-expanded`、`aria-selected` 和明确字段名称。

统计页替换范围：导出数据集、导出格式、功能、结果、趋势指标、趋势粒度和排行维度。日期输入继续使用原生日期控件。

## 3. 高度过渡

新增可复用的平滑尺寸指令。指令在 Vue 更新前记录元素当前的实际高度，在子内容更新完成后读取目标高度，并通过 Web Animations API 从旧像素高度过渡到新像素高度。

规则：

- 时长使用 `var(--duration-overlay)` 对应的 `220ms`；
- 缓动使用平稳的 `cubic-bezier(0.2, 0.8, 0.2, 1)`；
- 动画期间临时裁切溢出，结束后恢复原始样式；
- 快速连续刷新时从当前可见高度继续，不跳回更早状态；
- 高度没有变化时不创建动画；
- 浏览器不支持 Web Animations API 时直接使用最终布局，不阻塞功能。

统计页的趋势卡片和排行卡片接入该指令。加载提示出现或消失、空状态与数据列表互换、排行条数改变时，卡片都从现有高度自然过渡到新高度。桌面双栏的网格行高继续由内容决定，平板和移动端单列不使用固定高度。

## 4. 内容更新动画

新增内容变化指令。绑定值发生变化后，对对应内容执行：

```text
opacity: 0.25 -> 1
translateY(8px) -> translateY(0)
duration: 220ms
```

统计页在成功接收新响应时递增概况和分析 revision：

- 概况 revision 驱动四项 KPI 内容与三组指标行上浮；
- 分析 revision 驱动趋势图和排行内容上浮；
- 请求开始时不清空旧内容，旧数据在加载期间保持稳定；
- 请求失败时保留旧内容，只显示现有错误状态，不执行成功上浮动画。

动画只作用于内容层，不移动卡片边框、标题、筛选控件或语义色边线。

## 5. 减少动态效果

当 `prefers-reduced-motion: reduce` 生效时：

- 下拉菜单不执行位移动画；
- 高度直接到达最终值；
- 内容直接替换，不执行上浮；
- 控件、数据和焦点行为保持完整。

## 6. 测试与验收

单元测试覆盖：

- 自定义菜单渲染当前值，不暴露可见原生 `<select>`；
- 鼠标选择更新 `v-model` 并触发 `change`；
- 键盘导航、确认、Escape 和焦点恢复；
- 高度变化创建从旧高度到新高度的动画；
- 内容 revision 变化创建上浮动画；
- revision 未变化或减少动态效果时不创建动画；
- 统计页七个下拉菜单全部使用 `AppSelect`；
- 局部指标切换仍只刷新趋势与排行。

Playwright 覆盖桌面、平板和移动端：

- 展开菜单使用自定义列表框样式和正确选中态；
- 菜单不被趋势卡片或页面边缘裁切；
- 选择指标后 URL 和请求作用域保持不变；
- 刷新前后页面无横向溢出；
- 卡片具有高度动画，成功内容具有上浮动画；
- 所有可见控件都有可访问名称。

## 7. 非目标

- 本轮不替换统计页以外的原生下拉菜单；
- 不引入第三方组件库或动画库；
- 不改变统计 API、筛选语义、导出行为和数据定义；
- 不使用固定卡片高度掩盖内容尺寸变化；
- 不为装饰增加弹性、缩放或大幅位移动画。
